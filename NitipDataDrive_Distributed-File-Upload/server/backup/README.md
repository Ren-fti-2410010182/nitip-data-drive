# Backup Folder

Folder ini digunakan untuk menyimpan backup basis data dan script SQL.

## Isi Folder

- `data.sql` - file SQL untuk membuat/menambahkan tabel dan kolom yang digunakan oleh aplikasi.

## Tujuan

- Dokumentasi schema database.
- Cadangan konfigurasi database untuk restore atau migrasi.

> File ini tidak dijalankan langsung oleh server, tetapi dapat diimpor ke MySQL saat instalasi atau pemulihan.
